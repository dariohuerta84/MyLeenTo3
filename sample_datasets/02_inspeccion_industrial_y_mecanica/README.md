# Inspección Industrial, Metrología y Mecánica

## ¿Por qué estas imágenes son óptimas para MyLeenTo3?

- **Bordes afilados y alta varianza Laplaciana (hasta >3000), garantizando estimaciones de gradiente nítidas.**
- **Textura superficial de metal cepillado ideal para emparejamiento homográfico SIFT.**
- **Geometría regular apta para verificación de holguras mediante el Teorema del Eje Separador (SAT en 15 ejes) y cálculo de cuboides 9-DOF.**

## Enfoque Recomendado para Presentaciones
> Comprobar el ajuste del cuboide 9-DOF, las holguras entre componentes mecánicos y la exportación de la nube .PLY a software CAD/Blender.
